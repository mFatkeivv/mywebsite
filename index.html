Про сайт

Сайт створено в межах практичної роботи. Його мета — показати, як за допомогою HTML, CSS і JavaScript можна створити просту та зручну вебсторінку.

Основні технології

HTML

Створює структуру сторінки: заголовки, текст, зображення та посилання.

CSS

Допомагає оформити сайт: задає кольори, шрифти, відступи та розташування елементів.

JavaScript

Додає прості інтерактивні можливості та реакцію на дії користувача.
